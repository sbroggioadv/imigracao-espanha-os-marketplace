## Travas que o mercado erra
- Regulamento vigente é o **RD 1155/2024** (não o RD 557/2011)
- Representação administrativa **não** é título de abogado
- Golden visa, LMD e EX-31/EX-32 **fechados** para protocolo novo
- PEMA desde **12/06/2026** — reposición incompatível
- Brasileiro de origem: **2 anos** de residência apta ≠ cidadania automática
- Irregular ≠ expulsão automática
