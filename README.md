# imigracao-espanha-os-marketplace

Marketplace oficial do plugin **imigracao-espanha-os** (IA Combativa).

## O que é

Sistema operacional de imigração para a **Espanha** — 3 frentes no mesmo produto (imigrante · comercial · advogado). 52 skills, catálogo pós-reforma (RD 1155/2024), gates de vigência e de representação (OAB ≠ abogacía).

## Instalação (Claude Cowork / Claude Code)

1. Abra **Settings → Plugins**
2. Aba **Pessoal** → **+** (Uploads locais / Add marketplace)
3. Cole a URL deste repositório GitHub
4. Instale o plugin `imigracao-espanha-os`
5. Rode `/start-imigracao-espanha` e depois `/imigracao-espanha`

## Aviso

Este plugin **não substitui** abogado habilitado e colegiado na Espanha. Não garante visto, autorização, TIE ou nacionalidade.

O repositório é público para viabilizar a instalação. **Não é software livre** — o direito de uso é concedido pela compra (Kirvano). Ver `LICENSE`.
